# Full-Stack Master Implementation Plan (`plan.md`)
**Project:** Everyday Medicine Tracker (Android Mobile App + Cloud Backend)  
**Architecture:**  
- **Backend:** Python 3.11+, FastAPI, SQLAlchemy 2.0, Pydantic v2, Neon Serverless PostgreSQL (`psycopg` v3 & `psycopg2-binary`), Uvicorn  
- **Frontend & Mobile:** Vite + React, Tailwind CSS v4 (`@tailwindcss/vite`), Axios, TanStack Query v5 (`@tanstack/react-query`), Lucide React, Capacitor (`@capacitor/core`, `@capacitor/android`, `@capacitor/local-notifications`)  

---

## 0. Instructions for AI Agent (Antigravity)
You are tasked with building the complete full-stack application across two sibling directories: `backend/` and `frontend/`.
1. **Existing Environment Rules:**
   - Do **not** overwrite the existing `backend/.env` file containing the live Neon `DATABASE_URL`.
   - Maintain compatibility with both `psycopg` (v3) and `psycopg2-binary` in `backend/`.
   - Use Neon-safe connection pooling (`pool_pre_ping=True`, `pool_recycle=300`) so idle database wake-ups do not drop connections.
2. **Contract Alignment:**
   - Support both the versioned modular routes (`/api/v1/...`) and the direct alias routes (`/auth/login`, `/medicines`, `/medicines/today`, `/medicines/{medicine_id}/toggle`) so the frontend works seamlessly regardless of prefix configuration.
3. **Execution Order:**
   - First, complete and verify `backend/` (Part 1).
   - Second, scaffold and implement `frontend/` with Capacitor Android & Local Notifications (Part 2).

```text

│   │   ├── __init__.py
